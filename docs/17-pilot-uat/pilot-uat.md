# Phase 17 — Pilot / UAT

Pilot/UAT validates the workflow with representative synthetic cases before broad rollout.

Acceptance scenarios cover complete evidence, missing evidence, and dependency outage behavior. UAT verifies that human review remains mandatory, escalation dispositions are correct, and failure reasons are understandable to operations.

Defects discovered during pilot become reproducible tests or evaluation/red-team cases before promotion. The portfolio does not claim a real clinical pilot; this is an executable UAT framework and pilot plan using synthetic data.
